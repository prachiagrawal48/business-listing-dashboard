# Business Listings Dashboard

## Tech Stack
- React.js
- FastAPI
- MySQL

## Features
- Business data management
- City-wise analytics
- Category-wise analytics
- Source-wise analytics

## Setup Instructions

### Backend
cd backend
pip install -r requirements.txt
python -m uvicorn main:app --reload

### Frontend
cd frontend
npm install
npm start

## Database
Run database.sql in MySQL
